# Video Optimization Guide

## Problem Statement
Videos in the gallery and homepage carousel were stuttering and loading inconsistently due to:
- **No codec specification** — browsers waste ~200-500ms figuring out format
- **Single format** — no fallback if one fails; no quality options
- **No lazy loading** — all gallery videos load simultaneously
- **Poor buffering** — videos preload entire file instead of just metadata
- **No thumbnails** — "black screen" before first frame renders

## Solutions Implemented

### 1. OptimizedVideo Component (`components/video/OptimizedVideo.tsx`)
A reusable video player with intelligent optimization:

**Key Features:**
- **Multiple codec support**: Serves WebM (30-50% smaller) + MP4 (fallback) with explicit type hints
- **Lazy loading**: Videos only load when scrolled into view in gallery
- **Smart buffering**: Uses `preload="metadata"` by default for instant seek capability
- **Poster images**: Shows thumbnail while loading for better perceived performance
- **Type hints**: Explicit `type="video/webm; codecs=vp9,opus"` prevents browser guessing

**Usage:**
```tsx
<OptimizedVideo 
  src="/videos/demo.mp4"
  poster="/videos/demo_poster.jpg"
  loop
  muted
/>
```

### 2. Gallery Updates (`components/gallery/MasonryGrid.tsx`)
- Switched from basic `<video>` to `OptimizedVideo`
- Added lazy loading (videos load only when visible)
- Added poster image support for better UX
- Changed preload strategy to `metadata` (loads just enough to seek, not entire file)

### 3. Carousel Updates (`components/FeaturedCarousel.tsx`)
- Replaced bare `<video>` with `OptimizedVideo`
- Set `preload="auto"` for active carousel items (needs to play immediately)
- Videos now use proper codec hints for instant format detection

## Setup: Converting Videos to Multiple Formats

**Why both WebM and MP4?**
- **WebM**: ~30-50% smaller, VP9 codec, modern browsers (Chrome, Firefox, Edge)
- **MP4**: Larger but universal fallback, especially iOS/Safari

### Option A: Use FFmpeg (Recommended)
```bash
# Install ffmpeg (macOS)
brew install ffmpeg

# Convert single video
ffmpeg -i input.mp4 -c:v vp9 -b:v 1M -c:a opus output.webm

# Batch convert all MP4s in a directory
for file in *.mp4; do
  ffmpeg -i "$file" -c:v vp9 -b:v 1M -c:a opus "${file%.mp4}.webm"
done
```

**Quality settings:**
- `-b:v 1M` — 1 Mbps bitrate (good quality, smaller size)
- `-b:v 2M` — 2 Mbps bitrate (high quality, larger)
- `-b:v 500K` — 500 Kbps bitrate (lower quality, mobile-friendly)

### Option B: Use Handbrake (GUI)
1. Download [Handbrake](https://handbrake.fr/)
2. Open video → Format: WebM → Video Codec: VP9
3. Quality: CRF 28-32 (lower = better quality)
4. Audio: Opus, 128 kbps
5. Export

## Generating Poster Images

Poster images (thumbnails) are critical for perceived performance. Show these while video loads.

### Option A: FFmpeg (Extract first frame)
```bash
ffmpeg -i video.mp4 -ss 0 -vframes 1 -vf scale=1280:-1 video_poster.jpg

# Or at 5 seconds in (if first frame is dark)
ffmpeg -i video.mp4 -ss 5 -vframes 1 -vf scale=1280:-1 video_poster.jpg
```

### Option B: Manual (Video editor)
1. Open video in your video editor
2. Go to desired frame
3. Screenshot or export single frame as JPEG
4. Save as `video_poster.jpg` (same name, different extension)

### Naming Convention
```
video.mp4          ← Primary source
video.webm         ← WebM version (auto-generated by OptimizedVideo if exists)
video_poster.jpg   ← Thumbnail (used as poster attribute)
```

The component automatically:
- Looks for `.webm` version when `.mp4` is loaded
- Uses `_poster.jpg` as fallback poster path
- Falls back gracefully if WebM doesn't exist

## Common Issues & Fixes

### Issue: Videos still loading slowly
**Cause**: WebM files don't exist, browser defaults to MP4
**Fix**: Generate WebM versions using FFmpeg command above

### Issue: Poster image not showing
**Cause**: File named incorrectly or doesn't exist
**Fix**: Ensure poster file follows pattern `video_poster.jpg` (not `video-poster.jpg`)

### Issue: Carousel transitions are janky
**Cause**: Next video isn't preloaded, codec detection is slow
**Fix**: Ensure carousel uses `preload="auto"` (already set)

### Issue: Gallery videos have black bars or distortion
**Cause**: Incorrect aspect ratio conversion
**Fix**: Use `-vf scale=1280:-1` to preserve aspect ratio in FFmpeg

## Best Practices

1. **Keep WebM bitrate low** (1 Mbps): Smaller files = faster loads = better UX
2. **Always generate poster images**: 75-100ms perceived faster load time
3. **Use object-fit: cover**: Maintains aspect ratio without letterboxing
4. **Test on slow networks**: Use DevTools throttling (Fast 3G)
5. **Monitor file sizes**: Run after new videos uploaded
6. **Lazy load aggressively**: Use `preload="metadata"` for gallery items
